## Scope and result

The public C05 exporter receives SQL, catalog and training input only. It records
actual height/depth/slot choices, exact C02 proxy decompositions, evidence,
constraints/stops and selected artifact hashes. P06/P07 yields3 Boolean-path,
4 star and1 composite candidates per storage backend, with proved native heights
2/1/1 and declared finite-family exhaustion. This is not a global minimum-cost
search. The single-candidate composite case is a nondiscriminating control.

Candidate workflow-v2 retains the unchanged original height certificate and its
own upper witness. The collector independently rebuilds/validates the candidate
for the same source, replays the original certificate, and requires equal proved
height. This establishes the candidate's minimum height without substituting its
tree into the original proof. Ordinary compiled workflow-v1 retains witness
identity checks. No new private factory or query-class registration is used.

The generated split has15 traces/916 events across three SQL families: one train,
one calibration and three evaluation traces each. Physical tuple domains and
semantic traces are disjoint. Relational assignment and SQLite oracles agree on
initial/current results and raw deltas after every physical event. All loading
starts empty and remains charged. Evaluation changes relation update mix and
fan-out, reaching720 star result rows; rates are not claimed as measured Hz.
SQL families cross roles, explicitly not unseen-query-family generalization.

Every retained candidate passes independent verification on every split/mode
before timing. Any preflight/resource failure stops the packet; no surviving
subset is silently relabeled feasible. C05 choices freeze before timing, and
calibration-only affine mappings freeze before held-out warm-ups/samples. Native
choices never depend on evaluation costs. Search quality, proxy-estimation errors
and actual measured-candidate regret remain separate.
