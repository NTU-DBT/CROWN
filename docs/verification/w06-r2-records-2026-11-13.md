## Implemented boundary

One `CROWNAG2` family has protected length and body checksums, explicit versioned
payloads, full nullable SQL schema validation, canonical unique full group keys,
and complete empty epoch closure. Independent absent before/after tuples preserve
SQL NULL cells without signed-set reinterpretation. A bounded direct input
factory owns one byte buffer plus flat cell/replacement arrays. WAL validation
separates logged W, disposed I and runtime C; Reject advances I alone, one pending
head is retained, and new Inputs derive the required sink floor.

`crown_sql_aggregate_recovery` is an upper target exported as
`CROWN::sql_aggregate_recovery`. Existing runtime sources and dependencies do not
acquire a reverse dependency. There is no new production catch, undo/retry
framework, native field or native hot-path scan. Independent static review found
and root fixed a missing comparison charge/early tuple check, an impossible flag
combination and too-small output extent admission. Explicit noexcept cursor moves
support a future direct file owner without another allocation.
