# Frozen source packet evidence contracts

`selection-execution-freeze.json` preserves the old `native`, `execution`, `native_file_sha256`, `execution_file_sha256`, `expected_ctest_count`, `expected_test_names`, `expected_test_names_in_order`, `expected_compile_command_entries`, `expected_compile_units`, `configs`, `historical_manifest_file_hashes`, and `root_execution_helpers` shapes. It adds the exact ordered143 prefix, 24 `added_compile_units`, expected incremental/clean partitions, 12 `symbol_roles`, immutable publication FILE pins, manifest FILE pins, exact `integration_record_sha256`/`stage_receipt_sha256`, retained predecessor receipt/Release database/toolchain-cache pins, canonical compiler FILE pins, and scheduling/ceiling metadata. `predecessor_compiler_authority` binds the accepted C02 freeze and final matrix FILEs: cache choices, compiler aliases and bytes must agree before a new freeze can publish. Compiler aliases are canonicalized with conflicts rejected; repository-local Clang is not misclassified as an external tool. Historical12 manifest FILE hashes are preserved without evaluating their entries. Ordinary mutable status guides are outside the execution fingerprint.

Each `selection-<label>-summary.json` becomes terminal only at the end of the wrapper. `terminal:true`, `status:passed`, `exit_code:0`, `source_stable:true`, `identity_guards_stable:true`, and exact freeze/source identities are necessary execution conditions, not independent acceptance. A missing summary, `status:running`, failed command, partial LastTest log or absent direct-dependency evidence cannot pass. An interrupted preflight may leave no summary; that remains pending/failed for root review, never accepted. Existing evidence destinations are not overwritten.

Ordinary summaries retain `stages` with exact command argv, phase, log path/hash, exit code, elapsed seconds and wrapper ceiling. The final LastTest log is copied byte-for-byte to `selection-<label>-ctest-output.log`. A summary records the configured inventory scope but does not fabricate actual fresh/cached lists. The later matrix auditor must expose `actual_recompiled_units` and neutral `unchanged_units_not_recompiled`; each unchanged row must bind its exact retained predecessor object/argv/dependencies. New independent allocation differences still require content-derived root approval.

`selection-clean-artifacts-manifest.json` is the sole evolving receipt owned by the clean adapter, and is atomically replaced during its run. Its terminal state includes:

- `source_before`, `snapshot_inputs`, `snapshot_inputs_after_tests`, `source_after`, `snapshot_source`, `source_stable`, `temporary_removed`, and `identity_guards_stable`. The copied snapshot is rehashed before cleanup.
- `commands`: configure/build/test original and executed argv, wrapper ceiling, result, elapsed seconds and any termination details. Build/test gain only verbose output; their native settings are preserved.
- `retained`: exact `{source,retained,sha256}` records for the compile database, cache, CTest registration, flags/link/build recipes, compiler metadata, parser Makefile and final test logs when available.
- `dependency_records`: exactly238 target/source records, raw compiler argv, original directory/object/object hash, raw dependency spelling, resolved original dependency path, retained path and exact dependency-file hash. Each `included_inputs` list retains compiler spelling, observed path and canonical-input reference. `dependency_capture_complete:true` and `dependency_capture_phase:after_successful_build_before_ctest` are emitted only after the complete population is captured. Dependency text is copied verbatim and parsed using the accepted narrow single-target/single-colon Make-rule grammar; ambiguous rules and boundary-crossing aliases fail.
- `dependency_inputs`: unique canonical-path keys with exact hashes and explicit `scope`. `snapshot_source` binds a relative frozen execution file. `generated_build` additionally records its build-relative path and retained byte-copy path. `external_system` records current external input bytes. `dependency_inputs_stable_before_cleanup:true` requires all those files still match after the test phase. These current observations do not invent historical system/generated-header hashes for reused predecessor objects.
- `compile_database_pin` and `symbols_manifest`/`symbols_manifest_sha256` bind the common command inventory and twelve-role symbol receipt. Symbol dumps are retained before the original clean helper removes its temporary source/build. Temporary archives are hashed before/after collection; their bytes are not represented as retained archives.

The outer clean summary binds the final artifact-manifest FILE hash. This direct dependency retention replaces C02's separate clean watcher. No new watcher/helper is required. Clean fixture/compiler warnings, 96 parser C recipes, exact symbol members and old/new numeric outcomes remain independent-auditor obligations; the collection helpers do not waive them.

For ordinary unchanged units, the later auditor must state project dependencies, retained predecessor object equality, and compile-argv equality separately from current generated/system observations. The accepted C02 audit did not hash historical system/generated includes. It must not emit a blanket historical `source_and_dependency_bytes_equal` claim.

`selection-<label>-symbols.json` has `terminal:true`, `status:captured` only after all twelve archives remain stable and nm exits0. SAN adds a thirteenth raw record, `parser_undefined`; it is not a thirteenth archive role. `records` retain exact command/archive/dump/stderr paths, before/after archive hashes, result and raw dump hashes. Basic runtime probe separation is checked at collection; the later auditor must check all old12 RuntimeTestProbe methods, the two O07 hooks, new/preserved strong symbols and archive layering. Failed rows retain available raw log identities. A captured symbol receipt never accepts a live test run.

Root's `selection-sanitize-quiescence.json` must have `reviewer:root`, `decision:accepted_quiescent_sanitizer_window`, `no_other_expensive_work:true`, exact `freeze_sha256`, and `other_terminal_summaries` containing exactly debug/release/clang/clean-source `{path,sha256}` entries. Each referenced summary must be terminal for that freeze. A terminal failed earlier leg may be diagnosed while SAN proceeds; it is never promoted to passing. SAN rechecks the receipt and four immutable summary identities before each phase and at closure.

`c05-selection-root-jobs.json` remains the immutable preparation registry, pinned as a FILE. Only root updates the distinct live `c05-native-root-jobs.json`; these drivers never write either registry. Matrix authority, allocation-review records, final source audit and ledger transitions are separate root-owned work.
