from the accepted C01 trace-revision auditor.
It preserves that source-supported trace/run_dir normalization, raw row retention,
root allocation-review mechanism and terminal-only acceptance model. C02 changes
were retained by the first C02 package: C01 authority, exact 143/214 contracts,
new score/fault/JSON source contracts, pure/bridge layering, nine symbol roles,
direct dependency capture, explicit fresh/cached accounting, and final stability.
The new `audit.diff` contains only the dependency-alias repair: canonical paths,
same frozen bytes, source-boundary/alias conflict checks, and retained raw spellings.

The reviewer authored the separate independent public/integer fixture sources;
the producer authored the ranking implementation and ordinary/fault fixtures.
The literal independent tables and decimal-digit algorithms remain unchanged
native copies. Actual compilation with assertions, exact source/target bindings,
and terminal test outcomes carry their source contracts into the evidence audit.
The printed summaries are not presented as every assertion's raw value.

accepted C01 authority/auditor, C02 freeze/applied integration/publication/review,
root helpers and terminal dependency sidecar, retained C01 artifact mapping,
accepted preparation/publication receipts and output contracts, frozen source
contracts and vendor recipe. It does not recursively validate old source-entry
manifests. Current native/execution maps come only from the new freeze; ordinary
status prose is left to the separate final source audit.

Only this new proposal directory and `/tmp/crown-c02-matrix-audit-*` are writable
by its author. Native code, old review/audit packages and all root evidence are
preserved. Root alone executes the auditor and resolves any observed difference.
