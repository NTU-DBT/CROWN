# Frozen authority and result contract

The execution approval is a distinct immutable root FILE named `selection-matrix-audit-authority-<suffix>.json` under `build/verification`; the documented suffix is `execution-v1`. Its exact SHA is required on every invocation. It contains `reviewer=root`, `decision=accepted_evidence_only_auditor`, `card=C05`, exact `auditor` and `package` objects with repository-relative `path`/`sha256`, `freeze_sha256`, and exact `native`/`execution` objects.

The unsuffixed `selection-matrix-audit-authority.json` is deliberately rejected as an execution approval. It is reserved for the later source-audit authority that binds the canonical matrix receipt SHA and the exact canonical external raw-pin whitelist. This separation prevents a circular hash and avoids mutating any authority already included in a matrix's raw input pins.

An optional root allocation decision also requires both path and SHA. Its filename is `selection-allocation-review-<suffix>.json`, with `reviewer=root`, `decision=accepted_allocation_only`, `card=C05`, exact freeze/native/execution, and `entries`. Each entry contains `difference`, content-derived `id`, and a nonempty `reason`. The exact difference fields are `kind`, `test`, `configuration`, `baseline_configuration`, `row_index`, `before`, and `after`; the ID is SHA256 of compact sorted-key JSON for those fields. Only source-supported allocation-count substitutions qualify. Recovery counters, profile populations, literal scores, availability or semantics are never waived. An old C02 approval is not imported. Unused approvals fail once the full raw matrix is present.

Output is a new designated `selection-matrix-evidence-audit[-suffix].json` or `selection-matrix-audit-<suffix>.json` and sibling log, or a new file under the designated `/tmp/crown-c05-matrix-audit-` prefix. Existing output/log files are never overwritten. Exit0 means complete accepted matrix evidence; exit1 means audit errors; exit2 means pending legs/evidence; exit3 means unresolved allocation review after complete otherwise-valid evidence. Argument/preflight errors may produce no result and never count as acceptance.

The result retains the accepted predecessor structure: `auditor`, `input_pin_check`, `freeze`, `closing_source_guard`, `historical`, `preparation_authority`, per-configuration `matrix` and `symbols`, `allocation_differences`, `normalizations`, `read_evidence_sha256`, `errors`, `pending`, and explicit accepted flags. It adds `auditor_execution_authority` and an explicit historical-dependency scope statement. All actual read FILEs are pinned and rechecked before publication; native and execution scopes are checked again at closure. Mutable live logs are not admitted until their designated terminal summary is present.

Each passed configuration contains exact158 `registered_test_names`, `actual_order`, `test_outcomes`, per-test normalized/raw commands, numeric raw/comparison arrays, output digest, and a derived `numeric_rows_observed`. Every summary, registration, LastTest and verbose log has a raw FILE pin. Full cross-configuration comparison uses current Release as the fixed baseline; pending Release leaves that gate pending.

Compilation contains exact238 target/source rows, compiler/include/link evidence, runtime14/report6, ranking3 and bridge1 per variant, selection5 and bridge1 per variant. `dependencies` contains238 direct rows, `actual_recompiled_units`, exact actual verbose compiler commands, and neutral `unchanged_units_not_recompiled`. Ordinary `cached_predecessor_provenance` has status `audited_pass`, unit_count214, exact capture path/SHA, three true object/normalized-argv/frozen-project comparison booleans, and false historical-system/generated comparison booleans. Clean has unit_count0 and null comparison booleans, because no predecessor objects were reused.

Per-unit unchanged evidence binds current/retained object hashes, retained `.d` bytes, normalized argv equality and canonical frozen project dependencies. `actual_inputs`, `current_system_inputs` and `current_generated_inputs` separately describe current observations. Clean source inputs map to current frozen ROOT equivalents; generated includes map to retained copies; external system inputs map to actual readable canonical files. All enter the raw pin inventory. Repository-local Clang compiler/resource paths remain internal, with conflicting aliases rejected.

Symbols expose exactly twelve role results; the extra SAN parser-undefined record is not a thirteenth role. Removed clean archive bytes are represented only by their capture-time before/after hashes and retained symbol evidence; the auditor does not pretend that their bytes were retained. Fresh compile commands, object hashes captured before cleanup, generated recipes and explicit local links establish the clean-build scope.
