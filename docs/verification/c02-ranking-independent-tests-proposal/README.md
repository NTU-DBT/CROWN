# Independent C02 ranking tests — excluded preparation

These tests use the producer overlay in
[c02-baseline-ranking-proposal](../c02-baseline-ranking-proposal/). They do not
change native source, CMake, schemas, tests, task status, or any accepted package.
C02 remains `not_started`. Author-side verification is direct compilation and
linking only; root owns all execution and acceptance.

The public driver obtains actual P06 checked optimum handles and P07 immutable
candidate snapshots with finite search, replay, enumeration, depth, cell and
retention limits. It neither constructs proof/evidence factories nor imports a
caller-labelled tree as proof. The arithmetic driver alone includes the private
integer header and constructs raw integers; it never creates proof or runtime
evidence authority.

## Independent expectations

The public driver reads the existing Boolean R/S/T query and three literal tree
fixtures. Its own shape fingerprint ignores node labels/vector positions,
preserves scopes and occurrences, and compares sorted child strings. It uses
that fingerprint to identify all three actual retained structural keys and
requires the checked native optimum/height to be 2. Provider arrival order is
never used to label the expected trees.

The fixed expected depth vectors are native-S `(2,1,2)`, generalized-x `(1,1,2)`
and generalized-y `(2,1,1)`. A real committed no-op census R90/S5/T5 must produce
unreduced scores `195/100`, `105/100`, and `190/100`; resetting and mirroring R/T
reverses the last two values. The independently stated slot totals for one row
per source are `24`, `32`, and `32`. Every published node population and relation
or index contribution is checked against the literal fixture geometry, including
the generalized union bound of 2 even though the actual join values coincide.
These expected numbers are never computed by production ranking helpers.

The normalized alias fixture binds two aliases to physical table 1, while
physical table 0 is unused. Five no-op events for the shared base and two for
the unused table yield `10/7`, with two depth-one occurrences and no duplicate
denominator counting. The required memory input is the original physical source
count 2, even though filtering leaves one literal answer `{1}`. Per the preflight
contract, memory capture requests only routed bases; unused-table events remain
part of the workload denominator. Native snapshots and result cursors are
compared with independently specified row sets.

The integer oracle stores big-endian decimal digits. Addition uses decimal
carry, multiplication uses repeated addition and decimal shifts, and bit length
uses decimal long division by two. It does not inspect production limbs, use
production arithmetic for the expected side, use floating point, or rely on an
external big-integer library. Its constructed production operands are checked
immediately against the independent representation.

## Coverage

Eight public groups cover:

- Three candidate keys/heights, actual Boolean semantics, empty/prefix/full
  snapshots, unchanged original proof authority and deterministic height ties.
- Literal hot-relation reversal, live `rank_current` owner/epoch binding,
  candidate-local population/slot/index terms, and retained old results.
- Changed/no-op insert/erase census, private pending exclusion, abort/rollback,
  successful no-op staleness, rebuilt foreign owners, and owner movement.
- Off/empty/sampled-with-zero-detail roots, explicit fallback, independent data
  versus workload availability, capture/source limits, and processing/bit/time
  failure categories without fallback or partial selection.
- Equal statistical scores, full structural-key tie-breaking, retained prefixes,
  exact catalog-version binding rejection and invalid moved-from snapshots.
- Actual normalized physical alias mapping, unused-source denominator scope,
  literal result parity, and four distinct lowering/replay/identity budget caps.
- Delta mode/segment changes versus unchanged data epoch, actual session context,
  release/drop reasons, and owning history after runtime release.
- A 38-digit Decimal constant with a repeated output head: two physical rows,
  one literal filtered answer, slot bound `13`, a retained layout that rejects
  unequal repeated values, and exact/one-under modeled payload budgets.

Three integer groups cover direct uint64 conversions; all 16 boundaries at
multiples of 32 bits, adjacent values, zero/one and maximum 512-bit values;
products above 64/128/192 bits; pairwise exact arithmetic/ordering and bit caps;
exact/one-under work and decimal-byte limits; and unchanged operands/prior output
under aliased work/bit/export failures. Maximum decimal output is checked at the
155-byte boundary. The cross-product size printed by the executable is an
observed fixture population, not a predeclared execution result.

## Limits of this packet

No test pass, sanitizer pass, fault-sweep count or native matrix claim is made
by compilation/linking. These public tests use the production runtime ABI and
no testing probe or fabricated saturated statistics. Root's producer-side tests
separately cover ordinary/fault paths, saturation and nullary/unary memory
examples. Those are complementary evidence and must not be inferred from this
packet's existence.

The fixtures intentionally stay small and finite. They do not allocate enormous
real source tables to synthesize uint64-max runtime counts, prove every possible
tree/normalization shape, measure ranking overhead, predict engine cost, claim
allocator-total memory bounds, or establish global cost optimality. Raw wide
integer coverage does not convert saturated observed roots into exact facts.

The current strict consumers compile and link successfully against the complete
patched-header production closure. Exact source, input, artifact and package
manifests, zero-exit command/log records, [build results](BUILD_RESULTS.json)
and [root reproduction commands](ROOT_REPRODUCTION.md) accompany this packet.
Current strict execution and all sanitizer acceptance remain pending root.

Root accepted the separately frozen [integer-only checkpoint](checkpoints/integer-1/README.md):
54 operands, 2,916 ordered pairs, all 16 boundaries and three groups passed in
the ordinary private arithmetic driver. The result is retained in
`build/verification/c02-ranking-integer-root-attempt-1.json` with its provenance
and copied input tree. This is historical evidence from before the producer's
aggregate active-time ABI revision. Its frozen manifest **file** identity and
root's retained snapshot are authoritative; do not recheck its old live-input
manifest entries against revised producer headers. The current full closure
must rebuild both consumers and all affected producer objects. The checkpoint
does not accept the unfinished public suite, sanitizers or native integration.
