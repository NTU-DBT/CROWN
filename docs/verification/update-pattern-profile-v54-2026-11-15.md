## Claim and source

The bound is `O_Q(I + U)` successful logical Boolean native support actions,
amortized for a fixed compiled query/tree. I counts physical source rows at a
charged initialization; U counts physical source events including no-ops.
Reconstruction and plan replacement each charge their own initial state.

The counted support actions include input/child-key probes, matching reverse
visits, child-bit changes, survivor events and generalized upward propagation.
Storage operations, scalar widths, source adaptation, monitoring, allocation,
journal/rollback/retry, output and total CPU/delay are separate costs. A sequence
counter is not a work measurement and one event can still have many actions.

The source/paper audit remains the [V53 transfer and subtree argument](update-pattern-transfer-v53-2026-11-14.md).
Only its proved sufficient cases receive a positive profile. Unknown cases
remain unknown. The raw-FIFO height-three oscillator still refutes the naive
local-edge condition; no complete arbitrary-mixed or SQL FIFO decider is added.

| Interface | Exact retained meaning |
| --- | --- |
| `Selection::pattern_guarantee()` | Optional proved case for the actual selected candidate and compiled program |
| Pure `analysis()` / `plan()` | Same retained selected analysis and program, including source declaration, rules and edge bases |
| `CurrentSelection::pattern_guarantee()` | Optional selected case plus same-capture actual unrejected Session premises |
| Runtime `enforcement()` / `stamp()` | Captured declaration/origin/history/through-counters and physical owner/sequence |
| `selected_plan_matches_capture()` | Full selected and observed physical-program digest equality at that boundary |

The selected target can differ from the installed plan. A false match flag does
not attribute the target's bound to the observed executor. A true match identifies
the same program at capture without claiming that all earlier plan segments used
it. Retained captures remain readable after owner progress/rejection/release and
are historical facts. Restored history explicitly trusts the checkpoint.

Handles share the existing funded immutable selection/capture. They add no
allocation, row/index copy, account, clock, wire field, catch or update hook.
Access is fixed work; the physical digest comparison has fixed64-byte length.
Last-owner release or assignment can destroy the larger retained graph, and
explicit export/printing has separate host allocation/output costs.
