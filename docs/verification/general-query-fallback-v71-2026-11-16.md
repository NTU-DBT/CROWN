## Correctness and publication argument

Admission validates the original catalog/query, keeps actual recognition and
reason, and constructs a genuine empty-query physical source coordinator over
all original tables, constraints and backend settings. The original arbitrary
query is frozen separately under the same account. No original CROWN/GHD
certificate or executable/recovery identity is fabricated.

An iterative binding trail preserves ancestor variables while each atom scans
its own physical image. Repeated variables, aliases, constants and ignored terms
are checked before complete-witness projection. DISTINCT follows the original
ordered/repeated head. Boolean, nullary, contradictory and disconnected cases
retain classical set semantics. Deleting a nonlast witness preserves membership;
deleting the last one retracts it.

Current/prepared source captures own all physical data, including unused tables,
and admit row/capacity/scalar-byte work before deep copies. A pending capture
uses the changed table's journal reader and original retained indexed lease;
repeated captures never replenish that lease. Native cursors retire before the
source barrier. Capture refusal leaves the pending token available for rollback.
See [the capture contract](../source_images.md).

The source-only coordinator has no original atom routes: recomputation correctly
uses physical membership change and the original table-use mask, rather than
native alias crossings. Full answer/delta preparation precedes source commit.
A nonthrowing equal-allocator swap publishes prepared results, while the busy
guard spans old-state retirement. Refusal preserves full sources, exact answers
and sequence; owning outputs survive teardown.
