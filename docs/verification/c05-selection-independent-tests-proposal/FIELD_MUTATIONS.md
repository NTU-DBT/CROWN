# Full version-1 binding field checklist

This checklist follows the frozen design and the producer's explicit BINDING
field specification. It separates authored independent cases from coverage
that still needs producer/root evidence. None of the cases has been run by this
author. Diagnostic mutations return bytes only and are never submitted as a
proof, admitted normalized program, Selection or cache entry.

| Field family | Independent authored check | Limit or complementary coverage |
| --- | --- | --- |
| Primitive unsigned/signed words, lengths, record/array/optional tags | Independent byte-vector writer uses division/remainder, literal signed extremes and literal scalar/tree/core frames | No wire decoder or serialization import is claimed |
| Value variant; int64; string length/raw bytes; Boolean; Date days; canonical Decimal | All five alternatives, NUL/high bytes/empty, sign, extrema, Date versus integer, Decimal versus string and equivalent spellings | SQL NULL is tested only through absent optional Value in program records |
| Catalog version, ordered tables, table name/source schema version | Literal core plus individual version/name/version mutation; normalized physical/core Catalog version separately | Full table reordering is implicit in unchanged P07-v2 framing; a dedicated two-table reorder mutation is not authored here |
| Column name/type/nullable/collation/optional Decimal precision and scale | Literal all-type schema; individual name/type/nullable/Decimal presence/precision/scale; column order reversal | Collation has one supported enumerator; unknown collation admission is outside these byte-only cases |
| Unique constraint name/columns/status; foreign key name/columns/referenced table/referenced columns/status; ordered constraints | Every listed field mutated; constraint order reversed | Mutated records are byte fixtures, not new trusted/enforced schema claims |
| Optional row estimate; ordered distinct estimates/columns/value; ordered key hints/columns/reason | Presence/value, repeated projected columns, empty key-hint projection and changed reason | No estimate becomes an observed source cardinality |
| Query variables name/type/order; atoms occurrence/table/ordered term variant and payload; head variable/alias/order/repetition; contradiction | Literal terms variable/string/Decimal/ignored; term variant changes, variable/occurrence/table/head changes and ordered/repeated/empty head cases | Dedicated multi-variable/multi-atom sequence reordering is covered by the accepted P07-v2 lineage, not duplicated as a new C05 proof case |

| Deliberate exclusions: proof bytes/provenance, Usage/time, consumed state counters, abort/unread diagnostics, addresses, cache use/capacities | New real proof retained on hit; abort-only context fresh on hit; read-only finds write-installed entry; retained plans survive move/clear/drop; finite cache caps separate from key | No claim that every deliberate exclusion was toggled independently |

The small literal byte oracle independently verifies byte content, type separation
and append caps. Mutation inequality alone is not a proof of global injectivity.
The analytical versioned framing argument, full producer field tests and root
execution remain separate required evidence. Payload and slot quantities remain
declared C02/C05 proxies, never allocator/S05 bounds or a C03 cost model.
