# C05 frozen native registration proposal

This is an excluded, frozen publication proposal. It does not modify native
sources, the ledger, handoff, existing seals, C01/C02 packages or held C05
implementation inputs. Root owns every build, execution, final integration and
acceptance action. No CMake or CTest has been run for this publication overlay.

The target plan preserves the existing 143 CTest names, order, commands and
settings, then appends ten producer and five independent C05 tests. It adds five
pure selection units, one production and one testing bridge, fifteen consumer
units and two example objects: 24 new target/source entries, or 238 including
the existing 214. These are source-derived expectations pending actual native
configuration and compile-database review.

The pure library links only the existing ranking/plan/SQL/core chain. Both
optional bridges use the same runtime source and exactly one matching runtime
ABI. The runtime remains 14 units and each report library remains six units;
none gains a selection dependency. The existing JSON header/patch, CLI,
schemas, policy/proof/binding APIs and old test registrations are unchanged.

The proposal has 34 planned native destinations: three overwritten files
(`CMakeLists.txt`, `README.md`, `docs/native_build.md`) and 31 new files. Its
four-column `source-map.tsv` records each destination and source lineage. Root
has cleared all six independent fixture/consumer copies after all five ordinary
consumers passed their 22 groups. Those exact copies are now staged. Native
configuration and acceptance remain unperformed.

Destination documentation is now normalized from its temporary `.md.in` suffix
after C02 verification. The README/native_build copies were rebased on the
actual accepted current C02 text. The new guides are `docs/selection.md`,
`docs/selection_binding.md` and `docs/selection_accounting.md`. Their native
relative links must be checked through this publication's source-map projection
by the later C05 source audit; the excluded path is not a native build input.

The producer copy is the held implementation generation with the single
normalized SQL quoting correction. Its ten producer consumers and five
independent consumers passed in both ordinary and matching sanitizer variants.
The final source/input/package manifests bind that accepted preparation. The
corrected independent lineage combines the
original shared fixture/public/resources sources with the later isolated
binding/publication-fault corrections and the separately diagnosed cache-test
correction. No historical packet is rewritten. The correction retains the
unsupported arithmetic case as an explicit rejection with cache preservation
and supported retry, while preserving five supported distinct-key cases. Its
negative diagnostic remains provenance, not a passing cache test.

`LINEAGE.md` records the exact selected independent source/package identities,
the preserved failures and corrections, and the source review's scope. That
review found no concrete blocker in the held implementation; this publication
still requires its own final mapping and registration review.

`build/verification/c05-preparation-execution-completion.json`, has SHA-256
`43b420248cb77e1c6c9ba72fe6f29e3de80498740d19d53b0cafbad935d5f0c9`.

claim of deployment, automatic reoptimization, C03 calibration, allocator-byte
